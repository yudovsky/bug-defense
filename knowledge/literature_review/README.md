# Literature: lasers and light against insects and other arthropods

Primary studies that irradiated arthropods (and one slug) with lasers or high-intensity light. Titles, first authors and licences were checked against each paper's DOI record on Crossref in October 2026.

PDFs are included only for open-access papers whose licence allows redistribution. For everything else, follow the DOI link.

Filenames follow `<First author> et al. (<Year>) - <Title>.pdf`.
